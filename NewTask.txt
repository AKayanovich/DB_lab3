Условие задачи: «Анализ коллекции карт, колод и мета-связей в Hearthstone» (графовая база данных)

Предметная область

Типы узлов (вершин):

Карта (Card)
Свойства:
id (уникальный идентификатор)
name (название)
mana_cost (стоимость маны, целое число)
rarity (обычная, редкая, эпическая, легендарная)
card_type (существо, заклинание, оружие, герой)
attack (только для существ и оружия, целое число)
health (только для существ, целое число)
expansion (дополнение, в котором карта появилась, например, «Classic», «Forged in the Barrens», «March of the Lich King», «Whizbang's Workshop»)

Класс (Class)
Свойства:
name (маг, воин, жрец, разбойник, охотник, паладин, друид, чернокнижник, шаман, демон-охотник)
hero_power_name (название силы героя)

Колода (Deck)
Свойства:
id
name (например, «Агро Паладин», «Контроль Воин»)
archetype (агро, контроль, комбо, мидрейндж)
date_created (дата создания колоды, не путать с дополнением карт)

Игрок (Player)
Свойства:
nickname
rank (ранг в ладдере, например, Бронза 5, Легенда)

Типы связей (рёбер) и их свойства:

От Карта к Класс:
Тип ребра: BELONGS_TO_CLASS
Свойства ребра:
is_neutral (bool, true если карта нейтральная)

От Колода к Карта:
Тип ребра: INCLUDES_CARD
Свойства ребра:
quantity (1 или 2, для легендарных карт всегда 1)

От Игрок к Колода:
Тип ребра: OWNS_DECK
Свойства ребра:
is_favorite (bool)

От Игрок к Карта:
Тип ребра: HAS_CARD
Свойства ребра:
is_golden (bool)

От Карта к Карта:
Тип ребра: SYNERGY_WITH
Свойства ребра:
strength (целое число от 1 до 10, насколько одна карта усиливает другую)

От Карта к Карта:
Тип ребра: COUNTERS
Свойства ребра:
effectiveness (число от 0.0 до 1.0, эффективность контра)

Задания (что нужно выполнить с помощью графовых запросов):

Простые запросы на узлы и рёбра
1.1. Найти все карты класса «Маг» со стоимостью маны ≤ 3.
1.2. Для колоды с именем «Агро Охотник» вывести все карты и их количество (quantity).
1.3. Вывести всех игроков, у которых есть хотя бы одна легендарная карта (через рёбра HAS_CARD и свойство карты rarity).

Запросы с учётом свойств рёбер
2.1. Найти колоды, в которые включена карта «Ледяная стрела» (через рёбра INCLUDES_CARD). Для каждой колоды показать значение quantity этой карты.
2.2. Определить, у каких игроков есть избранные колоды (is_favorite = true), и сколько в каждой из таких колод карт стоимостью маны ≥ 7.

Поиск путей и анализ связей
3.1. Найти всех игроков, у которых в коллекции есть карта, синергирующая (SYNERGY_WITH) с какой-либо картой из их любимой колоды.
3.2. Есть ли путь длиной 3 от карты «Разбойник Воровство» до карты «Эдвин Ван Клиф» через рёбра SYNERGY_WITH? (Практика поиска связей между картами).
3.3. Для каждого класса построить «цепочку контрпиков»: Карта A COUNTERS Карту B COUNTERS Карту C … — найти самую длинную.

Агрегации и метрики
4.1. Какой класс имеет наибольшее количество синергий (рёбер SYNERGY_WITH) со своими картами?
4.2. Построить граф «игроки → колоды → карты → классы» и подсчитать, карты какого класса чаще всего встречаются в колодах игроков с рангом «Легенда».
4.3. Для каждой карты вычислить её «центральность по посредничеству» (betweenness centrality) в подграфе синергий — какие карты являются мостами между разными архетипами колод.

Задача на обновление данных
5.1. Добавить новую карту «Великий Червь» (стоимость 6, существо, класс Нейтральный, дополнение «Whizbang's Workshop»). Создать для неё рёбра SYNERGY_WITH с тремя существующими картами (выбрать любые подходящие по смыслу).
5.2. Удалить из коллекции игрока «Kolento» все карты, которые появились в дополнениях, выпущенных до 2023 года (например, все карты с expansion = «Classic», «Goblins vs Gnomes», «The Grand Tournament» и т.п. — список дополнений до 2023 года можно определить по хронологии Hearthstone). Другими словами, оставить только карты из дополнений 2023 года и позже.
